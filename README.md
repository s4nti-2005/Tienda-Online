# Mi Sitio Simple

Sitio web básico con HTML y CSS que cumple los requisitos del proyecto.

## Estructura
- `index.html` - HTML semántico (header, nav, main, section, footer)
- `styles.css` - Estilos con Flexbox, Grid, Media Queries, Google Fonts
- `images/` - Recursos multimedia locales

## Características
- Navegación con lista `<ul>` y enlaces internos
- Sección Productos con **Flexbox** (9 tarjetas responsivas)
- Sección Reseñas con **CSS Grid** (3 tarjetas responsivas)
- Formulario de contacto con Formspree + **Media Queries específicas**
- Diseño responsivo (mobile first) con breakpoints 768px y 480px
- Google Fonts (Inter)
- Gradiente en hero, background en secciones

## Uso
Abrir `index.html` en el navegador.
